Moth hover card: four directions

Each row is one real session (from /events, lightly adjusted to hit each case), drawn by today's card and by four new directions. The number beside each label is the card's height in px; green is shorter than today, orange taller. Every card is live: hover the PR rows and strips.

A. Tidy. Today's layout with the clutter taken out. The redundant status line goes, the message becomes a quoted block, agents get their own tinted tray with a live step line, and each PR is one row with a coloured status chip on the right; the whole row is the link.
  • Smallest change from today; shorter in every case.
  • Ten PRs is still ten lines.
B. Two-line PRs. Dace's idea: the title on top, then dot, number and state below, and the whole row clickable. Past four PRs it shows the first four (worst first) and "6 more".
  • Titles read in full, nothing squashed.
  • About 2× the height per PR; needs the cap to stay on screen.
C. Summed-up PRs. A strip like "1 ready · 8 drafts · 1 in review" in the PRs header, opening into the one-line list on hover. With three PRs or fewer it just shows the list.
  • The 10-PR card shrinks the most.
  • A hover-to-reveal step for the titles.
D. Two zones. The top is what it wants from you (state, question, message). A dark tray below holds the work: agents one line each (tag, live step, time), then PRs as small chips coloured by state, titles on hover.
  • Most glanceable, and the agents are clearly their own thing.
  • PR titles only appear on hover.

Notes

What agents can tell us. Each agent sends its description (the dispatch line), its type (opus-implement, so the model comes for free), its latest activity (the last tool call's description, which already carries the task tag, like "[shader-flame] Fix halo line"), and last (when we last heard from it). The new directions pull the tag out as a chip and show the step without it. Elapsed time isn't stored yet: the server would need to record started on an agent's first event (one line in Server.swift). The times here show what that would look like.
Duplicates in today's card. Background agents show twice: once under "Running:" (from tasks) and again under "Agents". The new directions list only the tasks that aren't an agent (like "[brass-depth] Restart the preview server"). The status line repeats the pill for "Finished its turn…" and "Waiting on N background tasks", and "Sleeping until you wake it" and "Snoozed until…" repeat a sleeping or snoozed pill, so those drop. Lines that add something ("Asks: …", "Wants permission to use Bash", an API error) stay.
Status vs. message. Today both render as violet, weight 500, the same size. In the new directions the state line is small and dim with a glyph, the question sits in a violet-tinted box, and the "You:" message is a quote in the card's bright ink with a violet rule on its left.
